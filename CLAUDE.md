# Weld site

Astro site for Weld, a Porto AI automation studio run by João Sousa (founder, first contact) Duarte (partner and builder) and Francisco Midões (social media and content).

- All copy lives in `src/content.ts`. Change text there, not in `index.astro`.
- Copy is European Portuguese, direct and casual. Never use em dashes (—) or en dashes as separators.
- Brand: forest #0A2119, forest mid #1B3E30, paper #F4F7F4, mint #3FA47A (accent only, never large backgrounds; small exceptions: the Weld node in the hero flow, the round CTA, primary buttons). Since v5 (Oct 2026): Archivo (variable, width axis) for display and body, IBM Plex Mono only for labels, numbers and UI details.
- Never add real client names or logos without written permission. Invented brands only, labelled as examples. The old chat demos in `public/demos/` (Oriva Dental, Pistão Peças, Pulso) are no longer linked from the site (the user found them weak and identical); the files stay so links in old emails keep working, and `/demos` redirects to `/`.
- Prices are not shown on the site; only the partnership models (projeto fechado, mensalidade, revenda, percentagem).
- Deploys automatically on Vercel from the main branch. Domain: https://weldstudio.pt (registered at Dominios.pt, nameservers pointed to Vercel DNS, so DNS records are managed with `vercel dns`). weld-site.vercel.app still works.
- Look (v5): dark workshop base (#07130E) with paper chapters. Sections carry `data-chapter="dark|paper"` and no background of their own; `shell.js` morphs the body colour between chapters and the nav follows. Styles in `src/styles/v5.css` (loaded after `global.css`, overrides tokens). No numbered meta labels ("01 / Serviços"), no pulsing dots, no icon-card grids. The W is a clean line mark, no particle effects. Keep it clearly distinct from rlagency.pt (no dark navy, no particle shapes, no round logo bubbles, no floating chat button, no centred phrase lighting up word by word).
- Home (v5, copy in `landing` in content.ts): giant headline "Soldamos IA ao teu negócio." with letters that stretch in and react to the mouse, a draggable n8n-style flow editor that runs example executions, manifesto with photos inside the text, two ways (direct / agency resale), 4 stacked service cards (`Stage.astro`), the lab (`Lab.astro` + `src/scripts/lab.js` + `src/styles/lab.css`, copy and data in `lab` in content.ts: three interactive demos, one per service and none of them a chat: invoice dragged into a spreadsheet with approval above 500 €, old vs new restaurant site slider with a working booking that lands in the owner's panel, bakery order board where moving a card messages the client and lowers stock), calculator, horizontal process with a weld seam, marquees, FAQ, `CtaBand` ("Vamos soldar?"). The margin seam (`#seam`) is off on the home page only.
- Motion: GSAP + ScrollTrigger + Lenis. `src/scripts/shell.js` (all pages: smooth scroll, page transition curtain with the W preloader once per session, cursor label on `[data-cursor]`, hide-on-scroll nav, chapter colours, `[data-marquee]`, `[data-rise]` headings, `[data-draw]` strokes, footer wordmark fill), `src/scripts/home.js` (home only), `src/scripts/site.js` (forms, calculator, demos, older components). Triggers created in shell.js use `refreshPriority: -1` so pins on the page are counted. Never put CSS transitions on `transform` of elements GSAP animates. Always respect prefers-reduced-motion.
- Two ways in: `/contacto` (3-step brief, demo grátis, now asks phone/email) and `/pedido` (detailed request; questions per service live in `order` in content.ts). Both save the request to the Weld panel through `src/scripts/weld-data.js` (Supabase RPC `weld_submit_lead`, publishable key) and show a success state; if that fails, `/pedido` tries `api/pedido.js` (Resend, needs RESEND_API_KEY) and both fall back to a prefilled mailto. Weld phone is `site.phone` (932 803 139), shown on /pedido, /contacto and the footer.
- Analytics: `weld-data.js` also records page views and events (`form_start`, `form_submit`, `cta`) via RPC `weld_track`, no cookies, one id per tab in sessionStorage; skipped on localhost, for bots, and on devices that opened `/?weld_ignore=1`. Everything is read in the private panel https://painel.weldstudio.pt (repo ~/Desktop/weld-painel).
- English version (Oct 2026): `public/i18n.js` holds a PT to EN dictionary and swaps the page text in the browser when the visitor picks EN (button `[data-lang-toggle]` in the header, choice in localStorage `weld-lang`, or `?lang=en`). It loads with `defer` before the Astro scripts so headings are translated before GSAP splits them; the home headline is rebuilt letter by letter in `heroTitle()`. Text written later by scripts is caught by a MutationObserver. **Any new or changed copy in content.ts or the scripts must also get its English line in `EN` (exact Portuguese string as key), otherwise it stays in Portuguese.**
